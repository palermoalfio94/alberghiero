# Accoglienza turistica

Attività interattive per gli studenti dell'istituto alberghiero.

Sito: https://palermoalfio94.github.io/alberghiero/

- **Che tipo di turista sei?** — questionario sul profilo del turista.
- **Trova la destinazione perfetta!** — attività di scelta della destinazione.

## Pubblicazione

GitHub Pages pubblica il ramo `main` dalla cartella principale (`/`).
La pagina iniziale è `index.html`; le due attività sono in `Accoglienza/`.
Non sono necessarie installazioni o compilazioni.

Per aggiornare il sito, modificare i file HTML, effettuare un commit e inviarlo al ramo `main`.
Il file `.gitignore` esclude gli altri documenti scolastici dalla pubblicazione.
